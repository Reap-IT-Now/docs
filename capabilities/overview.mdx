Start with the network context you have, then move into the investigation or operational workflow you need.

| Your goal | Guide | Where to find it in REAP |
| --- | --- | --- |
| Understand devices and their relationships | [Inventory and topology](/capabilities/inventory-and-topology) | **Inventory** and **Topology v2** |
| Ask a question about your network | [Chat](/capabilities/chat) | **Chat** |
| Review an incident and its context | [Incidents](/capabilities/incidents) | **Incidents** |
| Repeat an operational procedure | [Runbooks](/capabilities/runbooks) | **Runbooks** |
| Validate a change before and after implementation | [Change Management](/capabilities/change-management) | **Change Management** |
| Investigate vulnerability exposure | [CVEs](/capabilities/cves) | **CVEs** |
| Inspect collected configuration changes | [Running config](/capabilities/configuration-history) | **Inventory** → **Running config** |

## Start with a question

If your network is already connected, open [Chat](/capabilities/chat) and ask about a known site or device. Include the scope and what you want to understand, then inspect the evidence behind the response.

If you have not connected a site yet, follow the [quickstart](/getting-started/quickstart).

## Work from Slack

Use the [Slack integration](/integrations/slack) to ask network questions and work with supported incident and runbook flows in your team's workspace.
