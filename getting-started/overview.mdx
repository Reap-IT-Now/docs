REAP brings network context into investigation and operational workflows. Start by connecting a scoped part of your environment, then use the resulting evidence to ask questions and investigate changes.

## The building blocks

| Concept | What it represents |
| --- | --- |
| Organization | The workspace in which you manage access, network resources, and integrations. |
| Cluster | A grouping of connectors used to connect network environments to REAP. |
| Connector | The deployed component that provides connectivity to the network you want REAP to work with. |
| Site | A named network location or scope associated with your devices. |
| Credential | An authentication configuration used to access devices or services. |
| Discovery | The workflow that identifies devices within your selected network scope. |
| Integration | A connection to another system, such as Slack or ServiceNow. |
