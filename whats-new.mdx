## September 26, 2026

### Site setup and discovery guides: review edition

The setup guides now cover creating a site, attaching a cluster, deploying a connector on AWS EC2, configuring device credentials and assignments, and running and verifying discovery. Five screenshots illustrate the key steps.

The quickstart follows this sequence and finishes with a first network question. Sidebar overview links now use distinct names: **Setup overview**, **Choose a workflow**, and **Available integrations**.

[Follow the setup sequence](/deployment/overview). These technical guides remain **Draft** while deployment-specific requirements and customer workflows are validated.

## September 25, 2026

### Slack integration guide

The Slack guide is available with workspace installation, account linking, interaction targets, incident workflows, network questions, runbooks, and troubleshooting.

[Read the Slack guide](/integrations/slack).

### Documentation structure: review edition

The expanded documentation is organized into Getting started, Deployment, Capabilities, Integrations, and Security and administration. The landing page provides a setup path and direct links to security and support.

New technical guides are marked **Draft** in this review edition. They require product validation before publication.
